# Nestbox temperature, land cover, and nestling outcomes

Code and data to reproduce the analyses, figures, and tables for the manuscript "Interactive effects of hot temperatures and land use on cavity-nesting bird reproduction in California’s Central Valley", currently under consideration for publication in the journal *Ecosphere*. The study species are Western Bluebird (*Sialia mexicana*, WEBL) and Tree Swallow (*Tachycineta bicolor*, TRES). Nestboxes sit in four land-cover types (Forest, Orchard, Grassland, Row crop), and temperature loggers record conditions inside and outside the boxes.

The analysis asks how high nestbox temperatures, and their interaction with
land cover, are associated with:

| Response | Description |
|---|---|
| **Nestling growth** | Growth in body mass (g/day) |
| **Corticosterone** | Baseline (s1), stress-induced (s2), and absolute change (s2 − s1) in nestlings |
| **Nest survival** | Proportion of the clutch that fledged (incubation and nestling periods) |
| **Parental provisioning** | Provisioning rate, measured from camera images classified with a neural network (MobileNetV3) |

Growth is also modelled as a function of provisioning and corticosterone
(Figs 6 / S5). Temperature is summarized as mean/max/min daily temperature,
heat index, cumulative degree-hours above a threshold, and prior-day/prior-week
windows before sampling. Interactions of temperature with land cover and with
Julian date are tested with likelihood-ratio comparisons of nested models.

`Figure 1 nestbox-monitoring.png` in `figures/` is the only tracked figure. All
other figures and tables are regenerated by the workflow.

## Repository layout

```
Snakefile                    Workflow: models -> figures + tables
code/
  models.R                   Fits all models (5 sections); saves data/models_*.RData
  helpers.R                  Shared helpers (scaling, data prep, LRT tables, emmeans/emtrends wrappers)
  figures.R                  Main-text and supplement figures
  publication_tables.Rmd     Supplement tables (rendered to HTML with gt)
data/                        Input data (.rds); model outputs (models_*.RData) are generated here
figures/                     Generated figures (.png) and tables (.html)
```

### Abbreviations used in the code

- **Species:** WEBL = Western Bluebird, TRES = Tree Swallow
- **Corticosterone:** `s1` = baseline sample, `s2` = stress-induced sample, `abs` = absolute change (s2 − s1)
- **Temperature variables:** an `I` suffix (e.g. `meanmaxtempI`) is the inside-box logger, `O` is outside; `hi` = heat index; `priorday`/`priorweek` = window ending the day/week before sampling
- **Scaled variables:** original name + `_scaled`; squared terms + `_scaled_sq`

## Reproducing the results

The Snakefile is the recipe. It has four rules:

1. **`model_all`** runs `code/models.R`, which fits every model and writes five
   files: `data/models_growth.RData`, `models_cort.RData`,
   `models_survival.RData`, `models_provis.RData`, and `models_seasonal.RData`.
   The script has five sections: (1) growth, (2) corticosterone,
   (3) survival, (4) provisioning, (5) seasonal sensitivity (does adding a
   temperature × Julian date interaction improve fit?). Models are linear mixed
   models (`lme4`/`lmerTest`, random intercept for nest attempt), binomial GLMs
   for survival, and `glmmTMB` models for provisioning. Runtime is roughly
   7 minutes; the Snakefile allows up to 4 hours.
2. **`figures`** runs `code/figures.R`, which loads the model files and
   `temp.rds` and writes the figures.
3. **`tables`** renders `code/publication_tables.Rmd` to produce the supplement
   tables in `figures/*.html`.
4. **`all`** requests every figure and table below.

### Requirements

- **Git** and **Git Bash** to clone the repository and provide a crossplatform Linux-alike shell for Snakemake.
- **Snakemake** to run the workflow.
- **R** with the following packages: `tidyverse`, `lubridate`, `scales`,
  `viridis`, `ggeffects`, `ggimage`, `magick`, `cowplot`, `egg`, `patchwork`,
  `emmeans`, `multcomp`, `gt`, `glmmTMB`, `lme4`, `lmerTest`, `car`,
  `performance`, `modelsummary`, `dagitty`, `ggdag`, `igraph`, `hms`,
  `weathermetrics`, `future`, `magrittr`, and `rmarkdown`.
- **Pandoc** for rendering the tables. `PANDOC_DIR` at the top of the Snakefile
  points to the copy bundled with RStudio on the author's machine
  (`/c/Program Files/RStudio/resources/app/bin/quarto/bin/tools`); edit it to
  match your installation.

### How to run the Snakefile:

Run in a bash shell at the repository root:

```bash
snakemake --cores 1          # run everything
snakemake --cores 1 figures  # or a single rule/target
```

#### Note:

- `models.R` ends each section with `save(list = ls(), ...)`, so each
  `models_*.RData` file contains the section's models, data, and helper objects
  that `figures.R` and `publication_tables.Rmd` load.
- Generated files (`data/models_*.RData`, `figures/*.png`, `figures/*.html`,
  `.snakemake/`) are git-ignored.

## Models

`models.R` fits about 370 models, organised as sets of four and fit separately for each species: a full model with temperature × habitat interactions for both max and min temperature, two models with only one of the interactions (`_addmax`, `_addmin`), and a model with no interactions (`_noint`). They are compared with likelihood-ratio tests (`anova_int_tab()` in `helpers.R`), and the chosen model is then used for emmeans/emtrends contrasts. The results are captured in the tables and figures made from them.

| Section | Response | Model family | Temperature metrics tried | Main covariates |
|---|---|---|---|---|
| 1. Growth | `gweight` | Linear mixed model (`lmerTest::lmer`), random intercept for `attempt_id` | Mean daily max (inside box), weekly max heat index, prior-day max heat index, prior-week degree-hours > 30 °C, prior-week heat-index-hours > 30 | Min temperature × habitat, age, Julian date, year |
| 1. Growth ~ provisioning + corticosterone | `gweight` | Linear mixed model | Mean max temperature (quadratic in the baseline-cort model) | Baseline or absolute-change corticosterone, provisioning, humidity, age, condition |
| 2. Corticosterone | `sqrt(cort_s1)`, `sqrt(cort_s2)`, `sqrt(abs_change_cort)` | Linear mixed model, random intercept for `attempt_id` | About 8 metrics: mean max, prior-day max, prior-day max heat index, weekly max heat index, and cumulative heat-index-hours / degree-hours for day and week | Min temperature × habitat, age, Julian date, year |
| 3. Survival | Fledged vs. not fledged, out of clutch size | Binomial GLM (logit) | Mean max/min temperature, mean max/min heat index, degree-hours > 30 °C, heat-index-hours > 30 over the nest period | Habitat, Julian hatch date, year, site |
| 4. Provisioning | `valid_detections` | Zero-inflated negative binomial (`glmmTMB`), random intercept for `attempt_id` | `poly(mean_temp, 2)` or `poly(hi_30min, 2)` × habitat | Julian date, `poly(tod_h, 2)`, nestling age, year |
| 5. Seasonal sensitivity | As sections 1–4 | As sections 1–4 | Mean max temperature | Adds temperature × Julian date; compared with a `prior_model` without it |

Notes: the TRES growth models exclude records with an inside max temperature of 45 °C or more to avoid implausible temperatures, and the objects named `data_hihr25week_*` actually hold the heat-index-hours-over-30 variable - the calculation changed but the name of the variable did not.
